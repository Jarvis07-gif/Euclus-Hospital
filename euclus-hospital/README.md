# EUCLUS HOSPITAL

A modern, multi-page website for **EUCLUS HOSPITAL** with Home, About, Departments, Doctors, and appointment booking.

Each department lists more than one doctor. Booking filters doctors by the department you choose.

## Open the site

This is a static site (HTML, CSS, JavaScript). From this folder:

```bash
python3 -m http.server 4173
```

Then visit [http://localhost:4173](http://localhost:4173).

Appointments are saved in the browser (`localStorage`) so you can demo the flow without a backend.
